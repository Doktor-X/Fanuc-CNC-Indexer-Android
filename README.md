# CNC Index — Android Companion App

> A mobile companion to the **FANUC CNC Index** desktop tool.  
> Browse, search, and inspect your FANUC G-code program library right from your phone or tablet.

---

## Overview

The **FANUC PC desktop app** scans folders of FANUC G-code files, builds a searchable index, detects problems and duplicates, and exports a compact `index_android.json` file.

**CNC Index for Android** imports that file and gives you a fast, offline-capable interface to browse all your CNC programs — complete with tool lists, problem flags, and duplicate detection — without needing the PC to be on or connected.

---

## Features

| Feature | Details |
|---|---|
| 🔍 **Full-text search** | Search by program number, name, or filename. Supports regex and wildcards (`*`, `?`) |
| 🔢 **Program browser** | All programs sorted by O-number, showing name and tool count at a glance |
| 🛠️ **Tool list** | Tap any program to see its tools in clearly separated rows (requires `alati.json` import) |
| ✅ **Temporary machine status** | Tap a tool to mark it green when it is installed in the machine; tap again to clear it. This visual status is not saved after leaving the program screen |
| ⚠️ **Problem flag** | Programs containing non-ASCII characters are highlighted with a warning badge |
| 📋 **Duplicate detection** | Identical programs (by MD5 hash) are grouped together under a single card |
| 🗂️ **PC path display** | Shows the original file path from the PC so you always know where a program lives |
| 📅 **Last modified date** | Displays the file modification timestamp from the PC scan |
| 🌐 **Croatian / English UI** | Language can be switched from the top menu |
| 📴 **Fully offline** | All data is stored locally in a Room database — no network needed after import |

## How It Works

```
┌─────────────────────┐        index_android.json        ┌──────────────────────┐
│   FANUC PC App      │  ───────────────────────────────► │  CNC Index Android   │
│  (Python / Tkinter) │        alati.json (optional)      │  (Kotlin / Room)     │
└─────────────────────┘                                   └──────────────────────┘
  Scans CNC folders                                         Import → Browse → Search
  Detects duplicates
  Extracts tool numbers
  Exports JSON for Android
```

### Step-by-step workflow

1. On the PC, run the **FANUC CNC Index** desktop app and scan your CNC program folder.
2. Click **"Izvoz za Android"** (Export for Android) — this generates `index_android.json`.
3. Optionally export the tool name list (`alati.json`) from the same app.
4. Transfer the JSON file(s) to your Android device (USB, cloud drive, email, etc.).
5. Open **CNC Index** on Android → go to the **Import** tab.
6. Import `alati.json` first (if you have it), then `index_android.json`.
7. Switch to the **Search** tab and start browsing.

## JSON Format

### `index_android.json`

Generated by the PC app. Example:

```json
{
  "created_at": "2026-07-04T12:00:00.000000+00:00",
  "entries": [
    {
      "filename": "O0042.nc",
      "program_number": "42",
      "program_name": "FLANGE DRILL CYCLE",
      "filepath": "C:\\CNC\\Programs\\O0042.nc",
      "tools": [1, 5, 12, 20],
      "modified": 1720000000.0,
      "problem": false,
      "duplicate": false,
      "md5": "d41d8cd98f00b204e9800998ecf8427e"
    }
  ]
}
```

| Field | Type | Description |
|---|---|---|
| `created_at` | string (ISO 8601) | Timestamp of the export |
| `filename` | string | Filename on the PC |
| `program_number` | string \| null | FANUC O-number (digits only, e.g. `"42"`) |
| `program_name` | string \| null | Program name from the first `(...)` comment |
| `filepath` | string \| null | Absolute Windows path on the source PC |
| `tools` | int[] | Sorted list of T-numbers that precede an M06 call |
| `modified` | float | Unix timestamp of the file's last modification |
| `problem` | bool | `true` if the file contains non-ASCII bytes |
| `duplicate` | bool | `true` if another file with identical content exists |
| `md5` | string \| null | MD5 hex digest of the file contents |

### `alati.json`

Optional tool name dictionary. Keys are tool numbers prefixed with `T`, values are tool descriptions:

```json
{
  "T1":  "Ø10 SPIRAL DRILL",
  "T5":  "Ø50 FACE MILL",
  "T12": "Ø16 END MILL",
  "T20": "M8 TAP"
}
```

- **Database:** Room (SQLite) with migrations
- **JSON parsing:** Gson
- **Min SDK:** Android 8.0 (API 26)

## Building from Source

### Prerequisites

- Android Studio Hedgehog or newer  
- JDK 17+
- Gradle wrapper JAR (if missing, run the command below)

### Fetch the Gradle wrapper JAR (first time only)

```powershell
Invoke-WebRequest `
  -Uri "https://github.com/gradle/gradle/raw/v8.6.0/gradle/wrapper/gradle-wrapper.jar" `
  -OutFile "gradle\wrapper\gradle-wrapper.jar"
```

### Build debug APK

```bat
.\gradlew.bat assembleDebug
```

The APK will be at:
```
app\build\outputs\apk\debug\app-debug.apk
```

### Install directly to a connected device

```bat
.\gradlew.bat installDebug
```

## Database Migrations

The local Room database is versioned and migrated automatically on upgrade — no data loss on update.

| Version | Change |
|---|---|
| 1 → 2 | Added `tool_names` column |
| 2 → 3 | Added `md5_group` column for duplicate grouping |
| 3 → 4 | Added `filepath` column (PC source path) |
